# Free & Open-Source Framework
This framework is completely **free to use** and comes with a **free license**. You are free to modify it however you like and use it in your own projects. Please make sure to read the notes below before using it.


### 1. Changing the Game Window Size
To change the game window size, open `WindowSetup.gd` and find:

```gdscript
const WIN_SIZE := Vector2i(300, 300)
```
Change the values to your desired resolution. For example:
```gdscript
const WIN_SIZE := Vector2i(1280, 720)
```
`300` = Width (X)
`300` = Height (Y)

### 2. Moving the Window
You can freely move the game window by **holding the right mouse button and dragging**. This functionality is already included in `WindowSetup.gd`.
